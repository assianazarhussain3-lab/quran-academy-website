# Quran Academy Website 🌙📖

An Islamic education website designed to help learners understand the Quran with ease and clarity.

## 🌟 Features
- Multiple Quran lessons
- Surah-wise Tafseer (Al-Fatiha, Al-Baqarah, Yaseen)
- Beginner-friendly Quran learning pages
- Islamic Duas section
- Clean and simple UI
- Fully responsive design

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript

## 📂 Pages Included
- Home (index.html)
- About
- Courses
- Quran Beginner
- Tafseer Pages
- Duas
- Contact

This project was created as a learning and portfolio project to practice front-end web development while serving Islamic education.
